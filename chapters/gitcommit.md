## Saving Changes

## What is a Commit?

A commit is a **snapshot** of staged changes with a message describing what changed.

## Creating a Commit

```bash
git commit -m "Add initial project files"
```

## Writing Good Commit Messages

* Use present tense
* Be concise
* Describe *what* and *why*

## Viewing Commit History

```bash
git log
git log --oneline
```

## Amending a Commit

```bash
git commit --amend
```
